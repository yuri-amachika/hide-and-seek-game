# Code Review Skill

## 手順
1. 変更目的を1文で要約する。
2. リスクを抽出する（例外、境界値、互換性、入力検証、権限、外部I/O）。
3. 指摘を「重要度→根拠→影響→修正案」で書く。
4. テスト観点を提示し、必要なら最小テスト追加案を出す。
5. 可能なら最小修正 diff 案まで示す。
