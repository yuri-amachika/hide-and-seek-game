# Indexing Awareness Skill

## 概要
- エージェントがワークスペース内のディレクトリ構造や重要ファイルを自律的にインデックス化し、コードベース全体の把握力を高めます。

## 手順
1. **ディレクトリ構造の探索**: `list_dir` ツールなどを用いて、プロジェクトルートおよび主要なサブディレクトリの階層を走査します。
2. **シンボルの探索**: 必要に応じて `grep_search` ツールを活用し、設定ファイル、依存関係定義ファイル、主要クラスの定義場所を検索・記録します。
3. **SSoTとしての記録**: 把握した構造や主要パターンをメモリバンク（`systemPatterns.md` や `techContext.md`）に反映し、セッション間で知識を共有します。
