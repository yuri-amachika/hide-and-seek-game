# Security Scan Skill

## 概要
- 実装中に発生しうる一般的な脆弱性（OWASP Top 10など）や機密情報の漏洩を防ぐため、セキュリティの観点からコードを検査します。

## 手順
1. **静的解析・目視検査**: コード変更時に以下の項目を検証します。
   - SQLインジェクション: 文字列連結による動的クエリの作成を避け、プレースホルダー/パラメータ化クエリを使用しているか。
   - XSS (クロスサイトスクリプティング): ユーザー入力を適切にエスケープ・サニタイズしているか。
   - Secretsの漏洩: APIキー、秘密鍵、パスワードなどがコード中にハードコードされていないか。`.env` や環境変数から読み込む設計になっているか。
   - 依存パッケージ: 既知の脆弱性があるライブラリが指定されていないか。
2. **報告**: 脆弱性が検出された場合、直ちに「重要度（高/中/低）、原因、潜在的リスク、具体的な修正方法」を日本語で報告し、修正案を提案します。
