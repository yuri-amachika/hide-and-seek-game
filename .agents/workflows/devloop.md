# devloop

## 入力抽出
- 目的（何を満たすか）
- 制約（互換性/性能/期限/安全）
- 受け入れ条件（どうなったらOKか）
不足がある場合は最大3つまでに絞って質問する。

## Planning（必須）
- Implementation Plan と Task List を Artifacts で提示する。
- Plan に検証手順（テスト/手動確認/スクショまたは録画）を含める。
- 「Proceed」まで実装しない。

## 実装
- 最小差分で進める。
- 破壊的変更はリスクと回避策を提示し、承認待ちにする。

## 検証
- テスト手段を推定し、可能なら実行する。失敗したら原因→最小修正→再実行で緑にする。

## 成果物
- Review Changes（diff）を確認可能にする。
- Walkthrough（再現手順・確認観点・結果）を Artifacts で作成する。
