# review

## 概要
- 指定されたコード、あるいはステージングされた変更（diff）に対して、コードレビューを行います。
- ファイルの修正は原則行わず、問題点の指摘と改善コード案の提示にとどめます。

## 手順
1. **コード読み込み**: レビュー対象のコードや `git diff` を確認します。
2. **レビュー観点**: 
   - バグや脆弱性の有無（セキュアコーディング）
   - コードの可読性・保守性（SOLID原則、DRY、適切な命名）
   - パフォーマンス、エッジケースの処理
3. **フィードバック**: レビュー結果を「指摘内容、根拠、改善案」に整理して日本語で出力します。
