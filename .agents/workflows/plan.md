# plan

## 概要
- 与えられた指示や課題に対して、リサーチを行い、実装設計とタスクの細分化を行います。
- 設計以外のファイル変更（実装・リファクタリングなど）は絶対に行わないでください。

## 手順
1. **リサーチ**: 課題に関連するコードベースの現状を確認する（読み取り専用）。
2. **設計**: `implementation_plan.md` を Artifacts で作成し、目的、提案する変更点、影響範囲、検証計画を提示する。
3. **タスク分解**: `task.md` を Artifacts で作成し、TODOリストを作成する。
4. **確認要求**: 計画とタスクリストの作成完了後、ユーザーに確認を求め、フェーズを終了する。
