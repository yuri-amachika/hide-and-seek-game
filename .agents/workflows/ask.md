# ask

## 概要
- コードベースについての質問に答えたり、設計相談に乗ったりする読み取り専用モードです。
- ファイルの作成・編集・削除、および破壊的なコマンドの実行は一切禁止します。

## 手順
1. **コンテキスト理解**: 質問に関連するコードやファイルを読み込みます（読み取り専用）。
2. **分析と回答**: 技術的な論点、影響、ベストプラクティスに基づき、明確な回答や提案を日本語で記述します。
3. **提案**: 必要に応じて、コードを直接修正するのではなく「修正方針のコードスニペット」をチャット内に提示します。
