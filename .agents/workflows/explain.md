# explain

## 概要
- 指定されたファイル、クラス、関数、またはアルゴリズムについて、その役割、動作フロー、設計思想を解説します。
- 読み取り専用で動作し、コード変更は一切行いません。

## 手順
1. **コード読み込み**: 対象のコードを読み込み、依存関係やデータフローを把握します。
2. **解説の生成**: 
   - 概要（一言でいうと何か）
   - 詳細な構造・動作フロー
   - 設計上のポイントやメリット
   を整理して、日本語でわかりやすく出力します。
