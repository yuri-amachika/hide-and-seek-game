# commit-ja

## 概要
- `git diff --cached` でステージングされた変更を取得し、Conventional Commitsのタイプを用いつつ、詳細な説明を日本語で記述したコミットメッセージを生成します。
- ステージングされた変更がない場合は、メッセージを生成せず、ステージング（`git add`）を行うようユーザーに促します。

## 手順
1. **差分の取得**: `git diff --cached` を実行してステージングされた内容を確認します。
2. **フォーマット**:
   - `<type>(<scope>): <日本語の説明>` の形式で1行目に要約を記述。
   - 必要に応じて、詳細な変更理由（Why）を日本語でボディ部分に記述。
3. **コミットの実行または提示**: 生成したメッセージをチャットに提示し、ユーザーの確認を待つか、またはコミットコマンドを提案します。
