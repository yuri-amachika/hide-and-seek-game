# Project Brief: Hide Quickly 2D

## 概要
「Hide Quickly 2D」は、2Dの俯瞰視点（トップダウン）で描画されたモデルルームを舞台にした、生存者（Hider）と殺人鬼（Seeker）による対戦型サバイバルホラーかくれんぼゲームです。

## 主な目的
- 緊迫したホラー演出（心音、暗闇、懐中電灯、ノイズ等）を備えたブラウザゲームの提供。
- PC（キーボード＋マウス）とモバイル・タブレット（バーチャルジョイスティック＋タッチアクション）のハイブリッド操作。
- 近くに鬼が潜んでいる際の「息止め（心拍）ミニゲーム」によるインタラクティブなゲーム体験。
- Web Audio API を活用した、外部アセット不要の動的なホラー音響シンセサイズ。
