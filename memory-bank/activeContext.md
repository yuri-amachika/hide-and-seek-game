# Active Context: サバイバーゲーム体験の改善

## 現在の焦点
- サバイバー（Hider）のゲーム体験を向上させるための改善：
  1. テレビ台など隠れることができない家具（canHide: false）で「隠れる」コマンドが表示されてしまう不具合の修正。
  2. プレイヤー以外のAIサバイバー（AI Hider）を削除し、プレイヤー単独でのサバイバルホラー体験へ一本化。
  3. AIキラーが、プレイヤーが隠れている家具を捜索した際、即ゲームオーバーにするのではなく、家具から引きずり出して攻撃（ダメージ-1）を加え、一時無敵・加速（負傷ブースト）を付与して追跡フェーズに移行するロジックの実装。

## 最近の決定と合意事項
- **モード選択の廃止**: AIサバイバーが削除されるため、キラーとしてプレイする「Seekerモード」は廃止し、プレイヤーがサバイバーとしてプレイする「Hiderモード」のみに一本化。メニューからモード選択UIを削除する。
- **捜索時警告演出の追加**: キラーがプレイヤーの隠れている家具を捜索している間、画面に緊迫感のある警告演出を表示する。

## 次のステップ
- `implementation_plan.md` と `task.md` を作成し、プレイヤー以外のサバイバー削除やキラーの捜索攻撃ロジックの設計を明確にして、ユーザーの承認（Proceed）を得る。
- 承認後、実装、動作テスト、Walkthroughの報告を行う。
