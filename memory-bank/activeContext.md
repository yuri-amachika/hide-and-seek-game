# Active Context: プレイ体験改善とバグ修正の実装完了
 
## 現在の焦点
- テストプレイのフィードバックに基づき、サバイバーとキラーのプレイ体験を向上させる改修が完了しました：
  1. サバイバー：発電機の修理をするときのタイミング合わせミニゲーム（スキルチェック）の完全削除。
  2. サバイバー：家具（観葉植物など）に隠れた際の壁抜けバグの修正（隠れる直前の座標を保存し、出る時にはその座標に戻す）。
  3. サバイバーAI: 家具へ進入して隠れる際の「衝突解決による押し戻されバグ」の修正（ターゲット家具の衝突解決をバイパス）。
  4. サバイバーAI: 逃走中であってもキラーの視線を切った（壁の裏に回り込んだ）瞬間に、最寄りの家具へ隠れ込むインテリジェントな挙動の実装。
  5. キラー：手動捕獲ボタンアクションの不要化と、AIサバイバーに触れる（接触する）だけで自動的に捕獲する処理の実装。
  6. キラー：家具を調べる際、サバイバーが「いる時」と「いない時」で効果音および画面中央へのテキストフィードバック（リアクション）を明確に切り替える実装。
  7. キラー：暗闇マスクは維持した上で、チカチカする明滅エフェクト（フリッカー）や扇形の光線ガイドなどの不要な懐中電灯エフェクトの削除。
  8. キラーAI: プレイヤーが隠れている家具に到着した際、捜索する確率を最大 +50% 引き上げるアグレッシブな索敵。
  9. キラーAI: プレイヤー追跡中、プレイヤーが家具に逃げ込んで視界から消えた際に、即座にその最寄り家具をターゲットにして捜索を開始する追尾ロジックの実装。
  10. キラーAI: 捜索中のガサゴソ効果音の空間定位再生、頭上「❓」マーク描画、捜索家具の赤枠点滅演出の実装。
- `npm run build` による TypeScript の型チェックと Vite ビルドの成功を確認済み。

## 最近の決定と合意事項
- **衝突解決バイパスによる隠れるバグの解消**: 隠れるターゲット家具との衝突判定のみをスキップすることで、AIサバイバーが家具の中心部に完全に進入して隠れられるように修正。
- **AIキラー捜索演出の高度化**: 音響的・視覚的にキラーが探していることが明確にわかるようにし、ゲーム全体の不気味さとプレイの緊張感を大幅に向上。
