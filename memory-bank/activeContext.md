# Active Context: Hide Quickly 2D (手動デプロイ対応完了)

## 現在の焦点
- 手動デプロイを考慮した、ビルド時のアセット参照パスの相対パス化の対応。
- ローカルビルドを行い、成果物の検証を完了。

## 最近の決定と合意事項
- **マップ視認性の改善**: 床をフローリングブラウン（`#282420`）、壁を輪郭線が白いスレートグレー（`#64748b`）にし、歩行可能な道が一見して分かるよう視覚的に差別化。また、懐中電灯外の暗闇マスクの不透明度を `0.96` ➔ `0.72` に引き下げ、進行のしやすさとホラーの薄暗さを両立。
- **キラー攻撃機能の実装**: Seekerモードで走る/修理中のサバイバーに接近（距離 38px 以内）して攻撃（`Space`キー/タップ）することで捕獲できる通常攻撃を追加。
- **コマンドテキストのキラー化**: Seekerモードプレイ中のコマンドを「探す（家具）」「壊す（発電機）」「捕まえる（生存者）」に動的切り替え。
- **手動デプロイ用の相対パス化**: ユーザーによる手動デプロイに対応するため、`vite.config.ts` で `base: './'` に設定。さらに `index.html` 内の favicon 参照を `./vite.svg` へと相対パス化。これにより、任意のサブディレクトリ配下にデプロイされてもアセットやアイコンが正しく読み込まれるよう設定。
